## 🧾 Overview

This project implements Huffman coding for compression and decompression of files in a custom `.grin` format. It involves constructing a Huffman tree based on symbol frequencies, encoding input files into compressed binary streams, and decoding them using a serialized version of the tree embedded in the file.
